## 1. 起動手順

### 前提条件

- Node.js がインストールされていること
- `editor/.env` に OpenAI API キーが設定されていること

```
# editor/.env
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
```

### 起動コマンド

プロジェクトルート（`bemystyle-reel/`）で実行：

```bash
npm run editor
```

このコマンドで以下の2つが同時に起動します：

| サービス | URL | 役割 |
|---|---|---|
| 編集UI（Vite） | http://localhost:3001 | React フロントエンド |
| APIサーバー（Express） | http://localhost:3002 | OpenAI呼び出し・レンダリング制御 |

ブラウザで **http://localhost:3001** を開くと編集画面が表示されます。

## 2. 基本ワークフロー

### ステップ概要

```
テーマ入力 → ストーリー生成 → 14枚AI画像生成 → 保存 → 動画レンダリング
```

### ステップ 1：テーマ入力

- 画面中央の「テーマ入力」欄に動画のテーマを入力する
- 例：`猫カフェで働くOLの1日`、`登山で学んだ3つの教訓`

### ステップ 2：ストーリー生成

- 「ストーリー生成」ボタンをクリック
- GPT-4o により14枚分のスライドテキストが自動生成される
- 生成後、各スライドの内容を手動で編集することも可能

### ステップ 3：AI画像生成

- 「14枚AI画像生成」ボタンをクリック
- 各スライドに対応する画像を DALL-E 3 が順次生成する（数分かかる）
- 完了すると各スライドにサムネイルが表示される

### ステップ 4：保存

- 「保存」ボタンをクリックしてスライドデータをサーバーに書き込む
- 保存しないと動画レンダリングに反映されないため必須

### ステップ 5：動画レンダリング

- レンダーキューに追加してから「▶ キューレンダー」で動画を生成する
- 完了後は「ダウンロード」で `.mp4` ファイルを保存できる

## 3. ファクトリー実行の使い方

ファクトリー実行は「ストーリー生成 → 画像生成 → 保存 → レンダーキュー追加」を1ボタンで自動化する機能です。

### 実行手順

#### 1. テーマを入力する

「テーマ入力」欄にテーマを入力（ファクトリー実行ボタンの直上にある）。

#### 2. 「🏭 ファクトリー実行」ボタンをクリック

- 自動で以下が順番に実行される：
  1. ストーリー生成（GPT-4o）
  2. 14枚AI画像生成（DALL-E 3）
  3. スライドデータの保存
  4. レンダーキューへのバリアント追加

- 実行中はボタンが「🏭 実行中...」に変わり、進行状況がログで表示される

#### 3. 完了後の操作

ファクトリー実行が完了すると、レンダーキューにバリアントが追加されます。

**バリアント確認：スナップショットを見る**

- レンダーキューのアイテムにある「📸 スナップショットを見る」ボタンをクリック
- 生成されたスライドの内容（テキスト・画像）が一覧で確認できる

**差分確認：スナップショットを見る（Diff）**

- 「スナップショットを見る」の隣のボタンで変更差分を確認できる

**動画生成：キューレンダー**

- 「▶ キューレンダー」ボタンをクリック
- キューに入っている全バリアントの動画が順次レンダリングされる
- レンダリング中は「🎬 レンダリング中...」と表示される

**保存：ダウンロード**

- レンダリング完了後、各アイテムに「ダウンロード」リンクが表示される
- クリックすると `.mp4` ファイルがダウンロードされる

### ファクトリー履歴

- 過去のファクトリー実行結果は「ファクトリー履歴」パネルで確認できる
- スコア・タグ・テーマで絞り込み・お気に入り登録が可能

## 4. 各ボタン役割早見表

### メインエリア

| ボタン | 役割 |
|---|---|
| ストーリー生成 | GPT-4o でテーマから14枚分のスライドテキストを生成 |
| 14枚AI画像生成 | DALL-E 3 で各スライドの画像を生成 |
| 保存 | スライドデータをサーバーに書き込む（レンダリング前に必須） |

### ファクトリーパネル

| ボタン | 役割 |
|---|---|
| 🏭 ファクトリー実行 | ストーリー生成〜レンダーキュー追加を一括自動実行 |

### レンダーキューパネル

| ボタン | 役割 |
|---|---|
| ▶ キューレンダー | キュー内の全バリアントを順次レンダリング |
| 📸 スナップショットを見る | バリアントのスライド内容をプレビュー |
| スナップショットを隠す | プレビューを折りたたむ |
| ダウンロード | レンダリング済み `.mp4` をダウンロード |
| AIリライト分析 | スライド内容のAI改善提案を表示 |
| （削除ボタン） | キューからアイテムを削除 |

### Compare ダッシュボード

| ボタン | 役割 |
|---|---|
| ベストバリアント | 複数バリアントの比較・ベスト選出 |

## 5. よくあるエラーと対処法

### エラー：「OPENAI_API_KEY が設定されていません」

**原因：** `editor/.env` に API キーが書かれていないか、サーバー起動前に読み込まれていない。

**対処：**
1. `editor/.env` ファイルを確認する
   ```
   OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
   ```
2. ファイルが存在しない場合は新規作成する
3. `npm run editor` でサーバーを再起動する

---

### エラー：404 Not Found（API呼び出し時）

**原因：** APIサーバー（port 3002）が起動していない、またはエンドポイントのパスが間違っている。

**対処：**
1. ターミナルで `npm run editor` を再実行し、`[api]` のログが出ているか確認
2. ブラウザで http://localhost:3002 にアクセスし、サーバーが応答するか確認
3. ポート 3002 が他のプロセスで使用されていないか確認：
   ```bash
   lsof -i :3002
   ```

---

### エラー：画像生成がタイムアウトする

**原因：** DALL-E 3 の API レスポンスが遅い、またはネットワーク問題。

**対処：**
1. ブラウザの開発者ツール（F12）でネットワークエラーを確認
2. OpenAI の [ステータスページ](https://status.openai.com/) で障害がないか確認
3. 時間をおいて再試行する

---

### エラー：レンダリングが完了しない（進行が止まる）

**原因：** Remotion のレンダリングプロセスがクラッシュしている。

**対処：**
1. ターミナルの `[api]` ログにエラーメッセージが出ていないか確認
2. `npm run editor` を再起動する
3. スライドデータを再保存してからキューレンダーを再実行する

---

### 注意：保存せずにレンダリングすると古い内容で動画が生成される

ストーリー生成・画像生成後は必ず「保存」ボタンを押してから「▶ キューレンダー」を実行してください。保存をスキップすると直前に保存されたスライド内容で動画が生成されます。
