## 2. Phase21-I による画像生成時間の改善

### 実装詳細（コード確認済み）

| 項目 | Phase21-H 時点 | Phase21-I 以後 |
|---|---|---|
| 並列数 | 1（完全直列） | 3（`IMAGE_CONCURRENCY = 3`） |
| 生成方式 | `for await` ループ | `Promise.allSettled` バッチ |
| デフォルトモード | 節約モード 5枚 | 節約モード 5枚（変化なし） |

| 失敗時 | 全体再生成のみ | 失敗枚数のみ再試行（Phase21-K） |

| 最短 | 250秒 (4.2分) | 100秒 (1.7分) | **60% 短縮** |
| 平均 | 350秒 (5.8分) | 140秒 (2.3分) | **60% 短縮** |

**通常モード（14枚）**

| | Phase21-H（直列） | Phase21-L（3並列） | 短縮 |

| バッチ構成 | 14バッチ×1枚 | 5バッチ（3+3+3+3+2枚） | — |

## 7. 次フェーズ提案

### Phase21-M: 初回完成時「次回再利用できます」通知

- 初回AI生成完了→キャッシュ保存後に通知を1回だけ表示
- 「次回はこの画像を再利用できます（約4分早く完成します）」
- 再利用機能の発見率向上 → 2回目の実質3分達成率を上げる

### Phase21-N: 画像生成枚数の動的最適化

- 節約モードのデフォルト枚数を5枚 → 3枚に変更してループ割当を拡大
- 3枚×1バッチ = 〜1分 → 全体パイプラインを5分以内に短縮
- 「3分達成」に一番近づく単一変更

### Phase21-O: バリアント生成の高速化

- バリアント3件生成を並列化（現在直列）
- スコアリングとリライトの合計〜2分を〜1分に短縮
